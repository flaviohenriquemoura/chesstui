# ChessTUI

A terminal-based chess game built in Python, with a text user interface powered by the [Textual](https://github.com/Textualize/textual) library.

---

## Demo

<img src="https://github.com/flaviohenriquemoura/chesstui/blob/main/img/demo.gif" width="1024">

---

## Features
- [x] Local chess game with board flip
- [x] Real-time move order display
- [ ] Bluetooth chess game
- [ ] Chat (soon


---

## Technologies

| Library | Usage |
|---|---|
| [Textual](https://github.com/Textualize/textual) | TUI framework for the terminal interface |
| [Rich](https://github.com/Textualize/rich) | Styled and colorful text rendering |
| [python-chess](https://python-chess.readthedocs.io/) | Chess engine: move validation, check detection, etc. |

---

## Installation

**Requirements:** Python 3.8+

```bash
# Clone the repository
git clone https://github.com/flaviohenriquemoura/chesstui.git
cd chesstui

# Install dependencies
pip install -r requirements.txt
```
